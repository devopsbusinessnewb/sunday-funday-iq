Optimizer model

Complete-card tournament search.
IQ simulates game outcomes from market probabilities, creates approximately 101 opposing CBS-style confidence cards, then searches winner flips and confidence permutations. Candidate cards are judged primarily on Top-2 probability, with Win % as the secondary objective. The final card is re-tested with a larger simulation before it is shown.

How to use this

CBS → IQ → Optimize → Review → CBS.
Refresh CBS Data, refresh market prices if available, then Run Simulation. Apply Recommended Card only changes Sunday Funday IQ. It never submits picks to CBS. Use the recommendation list to make any final changes manually on CBS.
