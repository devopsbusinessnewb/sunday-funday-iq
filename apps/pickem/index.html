Optimizer model

State-aware tournament search.
IQ locks games that have started, fixes completed results, then simulates only the remaining uncertainty from market probabilities. It creates opposing CBS-style confidence cards and searches only changes that are still legally available. Candidate cards are judged primarily on Top-2 probability, with Win % as the secondary objective. Live odds refresh uses a public market feed with ESPN as fallback. The final card is re-tested with a larger simulation before it is shown.

How to use this

CBS → IQ → Optimize → Review → CBS.
Refresh CBS Data, refresh market prices if available, then Run Simulation. Apply Recommended Card only changes Sunday Funday IQ. It never submits picks to CBS. Use the recommendation list to make any final changes manually on CBS.
